# Phase 6A — lightweight learning checkpoint

User-authorized scope: free external learning, Brilliant-informed engagement, AI/software/UI/web/automation/Antigravity/YouTube paths, Google AI Ultra guidance, and all topics in the supplied AI infographic. This local slice is implemented; the wider Phase 6 remains open.

Nine paths, 43 original practice checkpoints:
- AI from foundations to agents: AI, ML, DL, generative AI, LLMs, prompting, RAG, multimodal AI, fine-tuning, safety, agentic AI.
- Antigravity and AI-assisted building, including Ultra quota/overage review.
- Software and web foundations.
- UI and responsive design.
- Frontend development.
- Backend and reliable APIs.
- Business automation.
- Generative AI and agent systems.
- YouTube visual design workshop.

Each path links to an existing provider's full learning material and supplies short original practice briefs. The YouTube path is explicitly a workshop. Checkpoints are starter exercises, not replacements for complete provider syllabi or proof of mastery.

## Working journey

Open Learn, explore a path, then Start this path. Open a lesson/reference in a separate tab. Save notes, mark a checkpoint complete, or reopen it. Add a practice task with a chosen duration and goal, then review its placement in Plan. Complete the scheduled session in Today to earn up to 15 XP. A checkpoint checkmark or repeated link click earns no XP. Each checkpoint has one stable practice task; existing tasks can be managed in Goals.

These tasks coexist with workouts, obligations and other goals through the same conflict-aware scheduler. No learning dates are silently committed. The available-window preview and explicit acceptance remain necessary because personal class/work commitments are not yet imported.
