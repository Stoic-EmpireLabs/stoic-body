# End-to-end experience research

Every row is a Stoic Body proposal, not a claim that a competitor implements the entire workflow. Benchmarks inform a design principle; all health constraints and confirmation/undo rules remain authoritative. This covers 26 journey steps and points each to implementation phases and acceptance evidence.

## Research at each development phase

- Phase 2: resolve platform/version/privacy/cost choices using official documentation; write the chosen behavior and rejected alternatives against these UX IDs.
- Phase 3: compare original prototypes against the benchmark tasks, including small screens, large text, keyboard and reduced motion. Measure actual taps and comprehension; review the coherent journey.
- Phase 4: verify schedule, recurrence, XP and reminders through real workflows; benchmark interaction friction without claiming competitors' internal algorithms are known.
- Phase 5: complete production diet/exercise evidence cards and independently specified calculations; competitor success does not establish clinical validity.
- Phase 6A: verify tutorial/quote provenance and import review; confirm link availability and accessible alternatives.
- Phase 6B: recheck store policies, regional prices, entitlements, content licensing and realistic operating costs before payment/release work.
- Phase 7: test the whole day and recovery paths on the selected devices; user-test the proposals and record negative results.
- Phase 8: refresh market/pricing observations for the release brief, document actual coverage, and publish only with the existing release approval.

No scheduled monitoring job is created. These research checks belong to the already defined development phases.
