# Learning research — reviewed 2026-10-04

Decision: a lightweight local catalog and progress companion, following the user's request to learn on existing free course sites. No copied curricula, third-party code runtime or whole repositories shipped in Stoic Body. Course paths below contain original starter checkpoints; the linked providers supply full courses.

## Product patterns and evidence

| Primary source | Observed pattern and evidence limits | Application and verification |
|---|---|---|
| [Brilliant XP](https://brilliant.org/help/features/what-is-xp/) (updated Sep 9, 2026), [coding framework](https://brilliant.org/coding-skills/) | Activity/effort scoring, weekly leagues and no extra XP for same-day lesson repeats. Public documentation does not supply a fixed per-lesson formula, retention lift or evidence that points cause learning. | Clear next action, practice deliverables and visible checkpoint progress. Keep the approved 15-XP focus award; repeat links/checkpoints earn nothing. Core/browser duplicate tests. No invented leaderboard or copied Brilliant lessons. |
| [The Odin Project](https://www.theodinproject.com/paths/full-stack-javascript) | Ordered full-stack course pathway and projects. Public interface reviewed; private learner accounts were not tested. | Prerequisites and original build checkpoints, linking to the full provider course. Progress is explicitly local/self-reported. |
| [Exercism JavaScript](https://exercism.org/tracks/javascript) | Focused practice exercises and external learning environment. | Free practice resource in fundamentals; no in-app code runner needed. |
| [n8n education](https://n8n.io/education/) | Free structured instruction through foundations/integrations/AI, including practice. Hosting and API costs are separate. | Staged automation exercises with synthetic data, failure handling and review before outreach. No imported automation engine. |

No paid native competitor accounts or proprietary internal engagement metrics were accessed. These are workflow comparisons, not a sales ranking or a claim that Stoic Body matches Brilliant's interactive teaching engine.

## Google AI Ultra / Antigravity

[Official plans](https://antigravity.google/docs/plans) distinguishes baseline quota, weekly limits and optional credit overages. Ultra has higher quota and third-party model access; it is not an unlimited-use guarantee. Settings exposes usage. This is documentation review, not inspection of the user's account. Costs and availability can change.

Course sources: [getting started](https://codelabs.developers.google.com/getting-started-google-antigravity), [building](https://codelabs.developers.google.com/building-with-google-antigravity). Original practice: define scope, review a plan, implement a small slice, test and inspect changes, record observed usage before scaling up. Never automate credit purchases or publish a project as a lesson side effect.
