# Stoic Body icon

Built-in image generation created the gold S shield, charcoal field and restrained crimson accent. The original is retained as `stoic-body-original.png`. `scripts/build-brand.mjs` only resizes/encodes delivery formats with the existing Sharp installation: a 512px web image and a seven-size Windows ICO (16–256px). No paid API or new dependency was used.

Prompt: “Create one production app icon for an app named Stoic Body, a disciplined daily life, fitness and learning planner. Square composition. A single bold geometric gold S monogram integrated into a very simple shield outline, with one restrained deep-crimson accent, centered on a near-black charcoal background. Calm, timeless Stoic character, high contrast, thick clean shapes, generous safe margin, readable at 32 pixels. No wordmark or lettering except S, faces, figures, weapons, fine details, mockup or watermark. Charcoal #121212, gold #D5B46B, crimson #A82935.”
