# Stoic Body phase rules

- Before implementing each phase, refresh research on the relevant leading products: performance evidence, interfaces, workflows, strengths and limitations. Record dated primary sources and the exact patterns adopted, adapted or rejected. Distinguish vendor claims, awards, downloads and revenue; never invent a bestseller ranking. Verify adopted behavior with an acceptance test. This is a direct user requirement from 2026-10-04, not optional background reading.
- Preserve the accepted black/red/gold identity and user-selectable appearance.
- Keep owner information under ignored private/; use synthetic test and public examples.
- Later-phase authorization does not erase unfinished acceptance requirements from earlier phases. Report both accurately.
