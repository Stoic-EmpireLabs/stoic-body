STOIC BODY - WINDOWS LOCAL PILOT

1. Extract the complete ZIP into a folder on your Windows desktop.
2. Double-click Start Stoic Body.cmd. Your browser opens the app.
3. Choose Create my account. Save your recovery key somewhere private.
4. Follow the welcome guide, answer questions at your pace, and set your own goals.
   Help & tour is always available. Sign out before another person uses your browser.

Windows 10/11 x64 is required. Node.js is included: no developer setup, npm,
subscription or external AI account is needed. This is an unsigned preview,
not a Microsoft Store installer. Follow your computer's security policies.

Your account starts empty. No developer profile, goals, meals or personal files
are shipped. Accounts separate data in the app; anyone who can read your Windows
files can read the unencrypted database. Use your own Windows account on shared PCs.
Do not expose the local port to the internet. No automatic cloud sync is included.
An account created on a different computer will not sign in here or share data.

START AND STOP
Closing the browser leaves the local service running. Use Stop Stoic Body.cmd
when finished. Reopen Start Stoic Body.cmd to continue. The app opens only on
this computer at http://127.0.0.1:4330. Nothing needs administrator access.

UPDATE AND BACKUP
Data is saved separately in %LOCALAPPDATA%\StoicBody (paste into File Explorer).
Stop the app before copying that whole folder to a private backup location.
Keep your recovery key separately. Recovery replaces your password without
email and invalidates previous sessions. Losing both password and key has no
self-service recovery. Automated backup/restore and export are not implemented.
To update: stop using the OLD download's Stop launcher, extract the new ZIP
into a new folder, then use its Start launcher. Your saved data remains in place.
Do not delete the data folder to update. Back up first; downgrade is unsupported.

WHAT WORKS
Local accounts, a resumable 20-question setup, a full-app tour, goals, tasks,
day-plan previews and acceptance, daily completion and XP, meal templates/logs,
workout planning/logs, measurements, learning resources and appearance settings.
Setup answers are retained; only explicitly described suggestions use them.
Plans are reviewed and edited by you. This is not fully automated coaching.

KNOWN LIMITS
No cross-device sync, native alarms, app-store installer, external AI coach,
automatic backups, or complete clinical/personalized nutrition prescription.
Theme settings are browser-local. External lessons/resources need internet.
Accounts and saved work persist after restart, but unsaved text drafts do not.

TROUBLESHOOTING
Extract ALL files before starting. If the port is busy, stop the previous copy
using its own Stop launcher. Do not kill unrelated software. Startup messages
are in the data folder's startup.log and startup-error.log. Keep these private.
Use a supported browser such as Edge or Chrome. An empty welcome screen is normal
for a new client; create your own account rather than using someone else's login.

The runtime is Node.js v24.19.0. Its full license and third-party notices are
included under runtime/LICENSE.txt. manifest.json records file SHA-256 hashes.
